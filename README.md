# Character Network — Novel Analysis Pipeline: Setup Guide

## Overview

This pipeline extracts, validates, and analyzes dialogue from a novel (`.docx`), producing a character interaction network enriched with vocabulary profiles. It is built entirely inside a single Jupyter notebook (`algorithm.ipynb`) and a set of browser-based interfaces backed by local Flask servers.
